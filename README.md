# 🤖 AI Resume Analyzer
## 📌 About the Project
AI Resume Analyzer is an AI-powered application built using Python.
It analyzes a resume and provides useful feedback to help students and job seekers improve their resumes.

## ✨ Features

- 📊 Resume score
- 💪 Identifies strengths
- 🔍 Finds areas for improvement
- 🛠️ Suggests useful skills
- 📝 Improves career objective
- 💼 Provides internship tips

## 🛠️ Technologies Used

- Python
- OpenAI API
- python-dotenv

## ⚙️ How It Works

1. User enters their resume.
2. The application sends the resume to an AI model.
3. The AI analyzes the resume.
4. The application displays suggestions and feedback.
